# MAB8-peli

Selainpohjainen matematiikkapeli MAB8-moduulin keskeisten perustaitojen harjoitteluun.

Peli syntyi opetushavainnosta: opiskelijoille funktion arvon laskeminen, derivaatan tulkinta ja kuvaajien lukeminen eivät aina automatisoidu pelkillä perinteisillä tehtävillä. Tavoitteena oli rakentaa mahdollisimman kevyt harjoitteluympäristö, joka toimii yhdestä HTML-tiedostosta ilman ulkoisia kirjastoja.

## Sisältö

Peli sisältää mm.

- funktion arvon laskemista (esim. f(2))
- ensimmäisen asteen yhtälöiden ratkaisemista
- derivaattafunktion tunnistamista
- kuvaajasta pääteltävää derivaatan merkkiä
- maksimi- ja minimikohtien tunnistamista merkkikaavioista

## Ominaisuudet

- toimii selaimessa
- ei vaadi asennusta
- ei vaadi kirjautumista
- toimii yhdestä HTML-tiedostosta
- paikallinen ennätystulos (localStorage)
- 60 sekunnin Survival Mode
- combo-pisteytys

## Käyttö

Avaa tiedosto selaimessa tai pelaa GitHub Pages -versiona.

Tavoitteena on vastata mahdollisimman moneen tehtävään oikein ennen ajan loppumista.

## Tietosuoja

Peli ei kerää henkilötietoja.

Selain tallentaa paikallisesti vain ennätystuloksen (hiscore) localStorageen. Tietoja ei lähetetä palvelimelle.

Käyttötilastoja kerätään anonyymisti
GoatCounter-palvelun avulla.
